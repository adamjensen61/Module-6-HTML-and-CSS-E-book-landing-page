# Module-6-HTML-and-CSS-E-book-landing-page

This project is a simple and responsive **E-book Selling Landing Page** created using **HTML and CSS** as part of my web development assignment.

## 📖 About the Project

The website is designed to promote and sell an e-book called **"Learn Python from Zero to Hero."** It includes a clean landing page with information about the book, pricing, reviews, and a simple user-friendly layout.

## ✨ Features

* Responsive navigation bar
* Hero section with e-book cover and price
* About the e-book section
* Customer reviews section
* Buy Now buttons
* FAQ section
* Responsive and clean design
* Custom e-book cover image

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, and responsiveness

## 🎯 Assignment Objective

The main objective of this assignment is to practice creating a complete webpage using **HTML and CSS**, while learning how to structure content, style elements, create navigation, use images, and build a responsive layout.
